# orders-worker

Go queue consumer. Generated by kickhub from `queue-worker` v1.0.0, target **local**.

## Layout

| Path | What it is |
|---|---|
| `cmd/worker` | Entry point and `handle`, where your logic goes |
| `internal/queue/queue.go` | Queue interface the worker depends on |
| `internal/queue/provider.go` | The only target-specific code: the broker adapter |
| `docker-compose.yml` | ElasticMQ, queue bootstrap and the worker |
| `.kickhub.yaml` | Records the template, version and parameters used |

## Run it

```sh
make up              # starts ElasticMQ, creates the queue, starts the worker
make send MSG=hello  # publishes one message
make logs            # watch the worker process it
make down
```

## Before production

- This repo provisions the messaging resources, not the compute. Deploy the image from `Dockerfile` to your platform of choice.
- Keep `handle` idempotent: delivery is at-least-once.
- Move Terraform state to a remote backend and commit `go.sum`.
